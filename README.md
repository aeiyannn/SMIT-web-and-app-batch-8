## Branch-Wise Code Access

The repository is structured branch-wise to provide a more organized learning experience. Follow these steps to access the relevant branch for your learning:

1. **Choose a Branch**: Switch to the branch corresponding to your desired topic or lecture.
   - Each branch contains the codebase and examples specific to that part of the course.
   - For more information on how to switch branches, refer to GitHub’s [guide on viewing branches](https://docs.github.com/en/repositories/working-with-branches/viewing-branches-in-your-repository).

2. **Download or Clone**: Once you’ve selected the required branch:
   - **Option 1** : Download the code directly as a ZIP file.
   - **Option 2** : Clone the repository using Git:
     ```bash
     git clone -b <branch-name> https://github.com/aeiyannn/SMIT-web-and-app-batch-8.git
     ```
